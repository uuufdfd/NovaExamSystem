# 发布审计与变更范围

## 结论

源码发布版已做数据最小化与规则扫描，但**不能据此宣称绝无隐私/授权风险**。项目所有者于 2026-11-25 明确同意公开，自有代码采用 MIT，并确认不存在其已知的学校额外公开限制。来源未确认的旧品牌图及含旧图截图已替换，第三方保留原许可。

## 纳入与排除

- 保留客户端、服务端现有目录、全部构建所需 C++ 文件、Qt 样式及演示模板；品牌图使用原创替换版。
- 保留运行桥接工具及基本部署入口，不自动运行它们。
- 不复制原 `.git`、IDE 状态、构建目录、缓存、日志、数据库、照片、人脸模板、运行账号配置、论文/答辩/学校提交文档及安装包。
- 不再分发来源/许可未随附的模型与 Haar XML；附上官方获取入口和许可证来源。
- 不复制原固定 IP 设置脚本、针对个人路径的临时修补脚本和数据库修复工具。它们在原项目中完整保留，不构成发布版正常构建依赖。

## 发布副本中的最小修改

1. 客户端默认服务器和辅助服务提示由原实验网地址改为 `127.0.0.1`，端口不变，继续支持 INI 和环境变量覆盖。
2. 移除指向原作者电脑的资源查找候选，保留相对路径；题库代理根目录改为相对项目路径。
3. 源码示例姓名改为明确的「演示学生/教师」，不导入旧库数据；演示账号与登录校验逻辑保留。
4. 初始化脚本不再回退到默认数据库密码，要求环境变量并校验模板支持的字符；SQL 示例使用明确占位符。
5. systemd 不再把数据库密码放入进程参数，改用服务端已支持的环境变量。
6. 麒麟启动入口不再强制覆盖宿主摄像头地址或执行信任标签/全局进程清理；保留本地摄像头及显式环境配置。
7. 客户端构建增加复制 `data/`，修正旧烟测风险分断言。没有大规模重构、删除业务模块或修改默认业务端口。

8. 公开阶段新增 CMAKE_AUTORCC，使已有 resources.qrc 中的品牌/QSS 引用编入目标；不修改业务 C++ 或网络逻辑。新增原创几何图标生成器及独立截图测试入口。

## 敏感信息检查

- 发布文本扫描覆盖常见 Token/私钥标记、原个人目录、原实验内网网段、已知个人学籍标记及手机号模式；最终结果由验证脚本给出。
- SQL 中保留的是应用自动生成的演示种子，不是原 MySQL 导出；人脸资料和真实成绩未复制。
- XLSX 检查其 ZIP/XML 内容，仅含演示题库结构；图片采用人工逐张查看，未声称完成 OCR 自动审计。
- 含旧品牌图的历史截图已排除。现有登录/题库截图使用实际 Qt 窗口、原创图标和新建 SQLite 演示库捕获，无像素编辑；仅显示回环地址及明确的演示身份，无实际学生记录、生物特征或私人部署信息。
- 原历史：枚举 **882 个可达对象**，对符合文件类型且小于 2 MiB 的 **237 个文本 blob** 进行规则扫描，得到 **133 条规则命中**（不是 133 个独立漏洞/密钥）。含内网地址、个人路径或旧数据库默认口令等；完整命中明细留本机，不迁入新仓库。
- 不包含不可达 Git 对象、未读取的外部目录、完整图像 OCR 或专业凭据扫描引擎覆盖保证。原仓库如曾公开过真实凭据，是否需要轮换仍须单独确认。
